# FTP like File Transfer

Homework on file transfer and TCP performance, done individually on Mininet. You will:

1. **implement** a minimal FTP-like protocol (`list` and `get`) in `apps/`;
2. **measure** download times for different file sizes, bandwidths and delays;
3. **explain** the results in terms of RTT, bandwidth-delay product and TCP congestion control.

Everything is in [`assignment.ipynb`](assignment.ipynb). It must run on Linux with Mininet installed, and Jupyter must run as root.
